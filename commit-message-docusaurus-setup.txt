docs: setup Docusaurus pour documentation CarRental

## Résumé
Installation et configuration de Docusaurus pour transformer les 29 fichiers markdown de documentation en un site web professionnel avec navigation, recherche et organisation par catégories.

## Fonctionnalités
- Site de documentation Docusaurus configuré
- Sidebar organisée par catégories (Introduction, Architecture, API, Workflows, etc.)
- Configuration pointant vers le dossier docs/ existant
- Page d'introduction créée
- Corrections MDX pour compatibilité (caractères =, >=, <=)
- Thème personnalisé pour CarRental

## Fichiers créés (structure Docusaurus)
1. website/ : Dossier complet du site Docusaurus
   - docusaurus.config.ts : Configuration principale
   - sidebars.ts : Organisation de la sidebar
   - package.json : Dépendances Docusaurus
   - src/ : Composants et styles
   - static/ : Assets statiques
   - blog/ : Dossier blog (désactivé)
   - docs/ : Dossier docs par défaut (non utilisé, on pointe vers ../docs)

## Fichiers créés (documentation)
1. docs/intro.md : Page d'introduction créée pour la documentation

## Fichiers modifiés
1. docs/07-data-dictionary.md : Corrections MDX (caractères spéciaux échappés pour compatibilité Docusaurus)

## Détails techniques
- Docusaurus 3.9.2 avec TypeScript
- Configuration pour utiliser ../docs comme source
- Sidebar organisée en 8 catégories principales
- Blog désactivé pour se concentrer sur la documentation
- Support du mode sombre
- Recherche intégrée (Algolia optionnel)
- Compatible avec les 29 fichiers markdown existants
