## Assurances Détaillées

### Assurance de Base (Incluse)

**Couverture :**
- Responsabilité civile obligatoire
- Protection contre le vol (franchise variable)
- Protection contre les dommages (franchise élevée)

**Franchises :**
- Dommages au véhicule : 1,500€ - 3,000€ selon catégorie
- Vol : 1,000€ - 2,000€ selon catégorie
- Bris de glace : 500€

**Caractéristiques :**
- Incluse dans le prix de base
- Obligatoire par la loi
- Attention : Franchises importantes à prévoir

---

### Assurance Standard (Option)

**Couverture :**
- Responsabilité civile
- Protection contre le vol (franchise réduite)
- Protection contre les dommages (franchise réduite)
- Bris de glace inclus

**Franchises :**
- Dommages au véhicule : 800€ - 1,500€ selon catégorie
- Vol : 500€ - 1,000€ selon catégorie
- Bris de glace : 0€ (inclus)

**Prix :**
- **Type** : PER_DAY
- **Montant** : 8€ - 15€/jour selon catégorie
- **Exemples** :
  - Économique : 8€/jour
  - Compact : 10€/jour
  - SUV : 12€/jour
  - Luxe : 15€/jour

**Avantages :**
- Réduction des franchises
- Protection bris de glace
- Tranquillité d'esprit

---

### Assurance Complète / Premium (Option)

**Couverture :**
- Responsabilité civile
- Protection contre le vol (franchise minimale)
- Protection contre les dommages (franchise minimale)
- Bris de glace inclus
- Protection pneus et jantes
- Protection contre les dommages intérieurs
- Assistance dépannage 24/7

**Franchises :**
- Dommages au véhicule : 300€ - 600€ selon catégorie
- Vol : 300€ - 500€ selon catégorie
- Bris de glace : 0€ (inclus)
- Pneus/Jantes : 0€ (inclus)
- Intérieur : 200€

**Prix :**
- **Type** : PER_DAY
- **Montant** : 15€ - 35€/jour selon catégorie
- **Exemples** :
  - Économique : 15€/jour
  - Compact : 18€/jour
  - SUV : 22€/jour
  - Luxe : 35€/jour

**Avantages :**
- Franchises minimales
- Protection complète
- Assistance 24/7 incluse
- Pas de stress en cas de sinistre

**Recommandation :** Pour les véhicules premium et les locations longues durées

---

### Assurance Zéro Franchise (Option Premium)

**Couverture :**
- Toutes les couvertures de l'assurance complète
- **Franchise : 0€** pour tous les dommages
- Protection complète vol et dommages
- Protection pneus, jantes, intérieur
- Assistance dépannage premium
- Véhicule de remplacement garanti

**Prix :**
- **Type** : PER_DAY
- **Montant** : 25€ - 60€/jour selon catégorie
- **Exemples** :
  - Économique : 25€/jour
  - Compact : 30€/jour
  - SUV : 40€/jour
  - Luxe : 60€/jour

**Avantages :**
- Aucune franchise
- Protection totale
- Service premium
- Véhicule de remplacement

**Recommandation :** Pour les véhicules de luxe et les clients exigeants

### Livraison et Retrait

#### Livraison à Domicile / Hôtel
- **Description** : Livraison du véhicule à l'adresse de votre choix
- **Prix** : 30€ - 80€ selon distance
- **Type** : FIXED
- **Conditions** :
  - Dans un rayon de 20km : 30€
  - 20-50km : 50€
  - > 50km : 80€
- **Disponible pour** : Toutes catégories

#### Retrait Hôtel / Aéroport
- **Description** : Retrait du véhicule à votre hôtel ou aéroport
- **Prix** : 25€ - 60€ selon distance
- **Type** : FIXED
- **Avantage** : Gain de temps

#### Livraison Aéroport Premium
- **Description** : Accueil à l'aéroport avec panneau nominatif
- **Prix** : 40€ - 100€
- **Type** : FIXED
- **Service** : Assistance bagages, véhicule prêt à l'arrivée

#### Retrait / Retour Lieu Différent
- **Description** : Retourner le véhicule dans une autre agence
- **Prix** : 50€ - 200€ selon distance
- **Type** : FIXED
- **Conditions** : Selon distance entre agences

## Calcul des Prix

### Exemple de Calcul Complet

**Réservation :**
- Véhicule : Peugeot 208 (Compact) - 45€/jour
- Durée : 5 jours
- Assurance : Complète - 18€/jour
- Services :
  - GPS : 8€/jour
  - Siège enfant : 5€/jour
  - Wi-Fi : 5€/jour
  - Livraison hôtel : 40€ (fixe)

**Calcul :**
```
Prix véhicule : 45€ × 5 = 225€
Assurance : 18€ × 5 = 90€
GPS : 8€ × 5 = 40€
Siège enfant : 5€ × 5 = 25€
Wi-Fi : 5€ × 5 = 25€
Livraison : 40€ (fixe)

Sous-total : 445€
TVA (20%) : 89€
Total : 534€

Acompte (30%) : 160.20€
Solde : 373.80€
```

## Modèle de Données Étendu

### Service Model avec Assurance

```typescript
export type ServiceType = 
  | 'INSURANCE'
  | 'NAVIGATION'
  | 'COMFORT'
  | 'DELIVERY'
  | 'DRIVER'
  | 'EQUIPMENT'
  | 'PREMIUM';

export type InsuranceLevel = 
  | 'BASE'      // Incluse
  | 'STANDARD'  // Option
  | 'COMPLETE'  // Option
  | 'ZERO_FRANCHISE'; // Option premium

export interface Service {
  id: string;
  name: string;
  description?: string;
  price: number;
  pricingType: ServicePricingType;
  serviceType: ServiceType;
  insuranceLevel?: InsuranceLevel; // Si type = INSURANCE
  franchise?: {
    damage?: number;
    theft?: number;
    glass?: number;
    tires?: number;
    interior?: number;
  };
  availableForCategories?: VehicleCategory[];
  icon?: string;
  active: boolean;
  createdAt: Date;
  updatedAt: Date;
}
```
