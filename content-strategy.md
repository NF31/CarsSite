# Stratégie de Contenu - CarRental

## 📋 Vue d'Ensemble

Ce document définit la stratégie de contenu pour CarRental, incluant le contenu par page, la navigation, et le SEO.

---

## 🎯 Objectifs de Contenu

1. **Informer** : Présenter clairement les services
2. **Convaincre** : Mettre en avant les avantages
3. **Guider** : Faciliter le processus de réservation
4. **Rassurer** : Inspirer confiance et sécurité

## 🔍 SEO

### Mots-clés Principaux

**Primaires :**
- location de voitures
- location de véhicules
- voiture de location
- louer une voiture

**Secondaires :**
- location voiture [ville]
- location voiture pas cher
- location voiture avec assurance
- location voiture week-end

### Meta Tags

#### Page d'Accueil
```html
<title>CarRental - Location de Voitures en Ligne</title>
<meta name="description" content="Réservez votre véhicule en ligne. Large choix de voitures, prix transparents, réservation simple et sécurisée.">
```

#### Page Détails Véhicule
```html
<title>[Marque] [Modèle] - Location de Voiture | CarRental</title>
<meta name="description" content="Louez [Marque] [Modèle] à partir de [Prix]€/jour. [Caractéristiques]. Disponible à [Lieu].">
```

### Structure URLs

```
/                          → Accueil
/vehicles                  → Liste véhicules
/vehicles/[id]             → Détails véhicule
/booking                   → Réservation
/booking/[id]              → Détails réservation
/about                     → À propos
/contact                   → Contact
/dashboard                 → Compte client
/admin                     → Interface admin
```

## 💬 Ton de Voix

### Principes

1. **Professionnel** mais accessible
2. **Clair** et direct
3. **Rassurant** pour inspirer confiance
4. **Actionnable** avec CTAs clairs

### Exemples

**❌ À éviter :**
- "Vous êtes invité à procéder à la sélection"
- "Veuillez compléter les champs ci-dessous"

**✅ À privilégier :**
- "Choisissez votre véhicule"
- "Remplissez vos informations"
